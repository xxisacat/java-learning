## 〇、讲义：四个零件

### 1. String —— 最特殊的类

**1.1 不可变**：String 一旦创建，内容不能改。所有看起来"能改"的方法（`trim` / `replace` / `substring` / `toLowerCase`）都是**返回一个新字符串**，原串不动。

→ 不接返回值 = 白干。这是「不干活的语句」家族的新变种，Q5 就是它。

**1.2 常量池与 ==** 【要背】

- `"红宝石"` 这种写死的字符串直接住在**常量池**里，同一份复用 → `"红宝石" == "红宝石"` 是 `true`
- `new String("红宝石")` 在堆上另造一份 → 和写死的那个 `==` 是 `false`
- 结论：**字符串比较一律 `equals`**；`==` 比的是"是不是同一个引用"
- `intern()` 能把堆上的串"拉回"常量池视角 —— 【了解】面试冷知识

**1.3 常用方法表**

| 想干的事 | 方法 | 备注 |
|---|---|---|
| 长度 | `s.length()` | 是方法！数组是 `arr.length` 属性，你的 Backpack 是 `size()` —— 三个长得都像，别混 |
| 取一个字符 | `s.charAt(i)` | 索引从 0 数；越界炸 `StringIndexOutOfBoundsException` |
| 截一段 | `s.substring(a, b)` | **含头不含尾** |
| 找位置 | `s.indexOf("x")` / `s.contains("x")` | 找不到返回 `-1` |
| 判断相等 | `s.equals(t)` / `s.equalsIgnoreCase(t)` | 永远不用 `==`，理由见 1.2 |
| 判空 | `s.isEmpty()` | 对 `null` 调任何方法都炸 —— 先判 null |
| 去两边空格 | `s.trim()` | **要接返回值！** |
| 替换 | `s.replace(a, b)` | 全局替换，返回新串 |
| 拆分 | `s.split(regex)` | 参数是**正则**；返回 `String[]` |
| 转数组 | `s.toCharArray()` | |
| 大小写 | `s.toLowerCase()` / `s.toUpperCase()` | |

**1.4 拼接陷阱**：`+` 从左到右算

- `"总伤害：" + 1 + 2` → `总伤害：12`（先拼 1，再拼 2）
- `1 + 2 + "点伤害"` → `3点伤害`（先把数算了，再拼）
- 想先算数：`"总伤害：" + (1 + 2)` → `总伤害：3`

**1.5 split 的两个点**

- 参数是**正则**不是普通字符串，`|` 在正则里有特殊含义，所以要写成 `\\|` 【要背这个写法】
- `"a,b,,".split(",")` 末尾空串会被丢掉 —— 【了解】，用的时候现查

### 2. StringBuilder —— 可变字符串

- String 每次拼接都造一条**新船**；StringBuilder 是**同一条船**，原地 `append`
- 核心方法：`append(什么都行)` / `insert` / `deleteCharAt` / `reverse` / `length()` / `toString()`
- 判据 【要背】：**拼 2~3 个 → 用 `+`；循环里拼 / 反复改 → StringBuilder**；要交回 String 用 `toString()`
- 回文判定一行流：`new StringBuilder(s).reverse().toString().equals(s)`（闭卷题用得上）
- `String.join("、", arr)` 也能拼接 —— 【了解】顺手知道即可

### 3. 包装类（Integer 为代表）

- 8 个基本类型各有包装类：`int→Integer`、`char→Character`，其余首字母大写
- **装箱 / 拆箱**：`Integer x = 5`（自动）= `Integer.valueOf(5)`；`int y = x`（自动）= `x.intValue()`
- **缓存陷阱** 【要背】：`valueOf` 对 **-128 ~ 127** 有缓存。所以：
  - `Integer a = 127, b = 127; a == b` → `true`
  - `Integer c = 128, d = 128; c == d` → `false`
  - 结论：**包装类比较一律 `equals`**（和 String 是同一笔账）
- `Integer.parseInt("123")` → int；`Integer.valueOf("123")` → Integer。装不进去（如 `"一二"`）→ `NumberFormatException`
- **拆箱 NPE** 【要背】：`Integer atk = null; int d = atk + 10;` 在**拆箱那一刻**炸 NPE。游戏里"未装备武器的攻击力为 null"最容易踩 —— 先判 null，再拆

### 4. 日期（快过中的快过，会用就行）

JDK8 之后主用 `LocalDate / LocalTime / LocalDateTime`：

```java
LocalDate today = LocalDate.now();
LocalDate last = LocalDate.of(2026, 10, 9);      // 上次签到
System.out.println(today);                        // 你跑的时候是当天，如 2026-10-16
System.out.println(today.plusDays(7));            // 一周后
System.out.println(today.isEqual(last));          // false —— 是不是同一天
System.out.println(last.isBefore(today));         // true  —— 在不在之前
```

- 格式化：`LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"))` 【了解】
- 老 API（`Date` / `SimpleDateFormat`）：**知道存在即可**，线程不安全，面试问到再说 【了解】
- `trim()` 够用；JDK11 还有个对 Unicode 空格更彻底的 `strip()` 【了解】
